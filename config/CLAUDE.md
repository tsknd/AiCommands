# 个人级 CLAUDE.md

> 本文件为用户级,对所有项目生效(会话启动时加载)。不放团队共享内容;团队级请写各项目自己的 CLAUDE.md。

## 会话压缩契约(自动压缩兜底用)

当本会话被 `/compact` 或上下文满自动压缩时,摘要**必须尽量保留**以下交接信息(带文件路径与标识符):

1. 已完成 / 进行中的工作与文件(路径)
2. 当前进度与下一步
3. 待办 TODO
4. 关键决策及理由
5. 踩过的坑(报错 / 错字段名 / 环境问题,带 `文件:行号`)

丢弃闲聊和已验证通过的中间调试步骤。

> 主动收尾用 `/hc` 命令(精准生成 + 落盘 `~/.claude/handoff/<项目名>/<sid>.md`);本契约只在「没来得及敲 `/hc` 就触发自动压缩」时兜底,两者互补。

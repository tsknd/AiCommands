## 第一步:判断是否需要压缩(别无脑生成摘要)

按会话的可观察特征判断(你读不到精确 token 数,按规模估即可):

- **不需要**(只占少数):本次会话很短、基本是问答/概念讨论、几乎没有工具调用或代码改动、历史信息量小。
- **需要**(默认倾向):会话有一定长度、做过实际代码改动/多文件探索、历史里堆了较多中间产物(长文件读取、重复命令输出、调试)、或到了任务收尾/阶段切换点。

拿不准时倾向「需要」——主动敲了 `/hc`,通常就是想收尾。

## 第二步:按判断结果分流

### A. 不需要压缩
只回复一句:「当前不需要压缩」+ 一句理由(如:会话短 / 纯概念讨论 / 还没到收尾)。**不生成摘要、不写文件**。结束。

### B. 需要压缩
按下面「会话交接清单」5 项整理当前会话,**逐项保留、带文件路径与标识符**,不要泛泛:

1. **已完成 / 进行中的工作与文件** — 涉及的租户/项目代码 + 改动路径(如 `server_tenant/app/Custom/{租户}/`、`front_pc/src/custom/{租户}/`、`tool_py/`)
2. **当前进度** — 做到哪一步、下一个具体动作
3. **待办 TODO** — 未完成的具体事项
4. **关键决策** — 取舍 / 选型及理由
5. **踩过的坑** — 报错、错字段名、环境问题,带 `文件:行号`

要求:
- 具体(路径 / 标识符 / 行号),不要空话
- 丢弃闲聊、已验证通过的中间调试、重复的工具输出
- 某项没有就写「无」,不要编

落盘与输出:
1. **定项目名**:当前工作目录最后一段(如 `...\xfawu` → `xfawu`、`...\test\AiCommands` → `AiCommands`)。
2. **定会话短 id**:读环境变量 `CLAUDE_CODE_SESSION_ID` 取前 8 位,一行 bash:
   ```bash
   echo "${CLAUDE_CODE_SESSION_ID:0:8}"
   ```
   这是 harness 给的当前会话标识,可靠。**不要用「项目 projects 目录下 mtime 最新的 jsonl」判断当前会话**——有子会话/agent 时它会被污染(实测最新 jsonl 常是子 agent 的,不是当前会话)。
3. 写入 `~/.claude/handoff/<项目名>/<sid>.md`(**同会话覆盖、跨会话隔离**;Windows 下即 `C:\Users\<你>\.claude\handoff\<项目名>\<sid>.md`)。文件开头两行:
   ```
   # 交接 · <项目名> · <sid> · <YYYY-MM-DD>
   > 主题:<一句话概括本次会话在做什么>
   ```
   再接上面 5 项摘要正文。
4. 在对话里输出这份摘要。
5. 提示:现在运行 `/compact` 释放上下文(信息已落盘,可放心压缩)。

> 说明:`handoff/**/*.md` 只是落盘存档,Claude Code **不会自动加载**它,不影响任何会话上下文;`/compact` 压缩读的是对话里的摘要,不读这些文件。落盘只为事后回看 / 跨会话恢复。
